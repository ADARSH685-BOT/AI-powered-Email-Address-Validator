# 🛡️ AI-Powered Email Validator

A premium, full-stack web application that uses **Claude 3.5 Sonnet** to perform deep neural validation of email addresses. 

![Screenshot](https://via.placeholder.com/800x400?text=AI+Email+Validator+Interface)

## ✨ Features
- **Neural Analysis**: Detects typos, disposable domains, and syntax errors using advanced AI.
- **Real-time Feedback**: Animated score ring and instant validation results.
- **Premium Design**: Stunning dark-mode interface with glassmorphism aesthetics.
- **Smart Suggestions**: Automatically suggests corrections for common domain typos.
- **Robust Backend**: Powered by FastAPI and Anthropic's Claude API.

## 🚀 Quick Start

### 1. Installation
```bash
pip install -r requirements.txt
```

### 2. Set API Key (Optional)
```bash
export ANTHROPIC_API_KEY='your-api-key-here'
```
*Note: The app includes a built-in mock mode if no API key is provided.*

### 3. Run the App
```bash
python email_validator.py
```
Visit `http://localhost:8000` in your browser.

## 🛠️ Technology Stack
- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Backend**: Python 3.11+, FastAPI, Uvicorn
- **AI Engine**: Anthropic Claude 3.5 Sonnet
- **Icons**: Lucide Icons
- **Fonts**: Google Fonts (Inter & Outfit)
